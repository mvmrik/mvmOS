## What mvmOS is

mvmOS is a self-hosted desktop environment for a Linux server. You install it on infrastructure you control, then use the browser as the desktop interface for system tools, built-in apps, and Store apps.

## Core areas

- [[Desktop]] is the browser workspace where windows, menus, themes, and applications live.
- [[Users and access]] manages local accounts, sessions, and access to the installation.
- [[Files and backups]] covers file management, backups, and recovery-oriented administration.
- [[Apps and Store]] explains built-in tools, Store apps, installation, and updates.
- [[Settings and system]] covers configuration, services, packages, domains, and server administration.

## A local-first model

Your mvmOS data remains on the server where you installed mvmOS. Features that intentionally contact mvmos.org, such as optional error reports or future Premium licensing, are described separately and do not turn the installation into a centrally hosted account.
