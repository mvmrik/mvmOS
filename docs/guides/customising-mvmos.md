## Personalise the desktop

Settings covers language and regional preferences, wallpaper, display choices, screensaver behaviour, and Start Menu configuration. mvmOS ships with English and Bulgarian interface text.

## Widgets and themes

[[App Store]] can manage widget and theme stores alongside application stores. Widgets extend the desktop or taskbar experience; themes change the visual presentation. On mobile, widgets are presented on a dedicated widgets page rather than crowding the desktop.

## Extensions and plugins

mvmOS can load extensions and plugins through its Core extension system. Treat third-party extensions as code that runs on your server: use trusted sources, read their documentation, and test them before enabling them on an important installation.
